# Security Policy

## This is a demo system

CareFlow is a proof of concept, not a production healthcare system and not a medical device.

- **Synthetic data only.** Seeded patients, doctors, registration numbers and prescriptions are invented. Evaluation audio is generated by text-to-speech; there are no real recordings.
- **Do not enter real health information.** The Gemini free tier allows Google to use submitted content to improve its products.
- Raw audio is processed in memory and never stored. Analytics store timings and intent labels, not transcripts.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/RahulBailur/CareFlow/security/advisories/new)
rather than opening a public issue.

Include what you found, how to reproduce it, and the impact you expect. As a solo project there is no guaranteed response time, but reports are read and acknowledged.

## If a secret is committed

Revoke the key at its provider immediately (for a Gemini key, in Google AI Studio), then remove it from the Git history. Removing it from history alone is not enough.
